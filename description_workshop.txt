[h1] UI Editor [/h1]  
This is a mod that allows you to customize the position of ANY UI IN THE GAME.
It also has a lot more useful features:

[h2] Features [/h2]
- Drag and drop any UI to your liking (chat, hotbar, inventory, map, etc)
- Save your layouts and share with your friends!
- Toggle resource packs in-game
- Toggle interface layers and UI elements from vanilla or any mod.

[h2] How to use [/h2]
- You will find new icons under the inventory which can be used to toggle the editor.
- If you already have either Mod Reloader, CheatSheet, DragonLens or Heros Mod, the panels are automatically added to all of those menus.
- To create a layout, simply enter edit mode via the UI Editor panel and move the UI to your liking, then press Layouts -> Save this layout.
